# Orbit · 출근기록 (옛 Horarium, MAENG_worklog)

2026-11-11 이름을 **Orbit** 으로 바꿨습니다(DESIGN §37). 로고는 가운데 원 + 가는 고리 + 고리를 도는 작은 위성이고(위성은 지금 '분'을 가리키는 분침), `logo\make_orbit.py` 로 다시 만듭니다. 화면은 DESIGN §40~§43 — 어두운 화면이 기본이고, 폰은 하루 궤도(24시간 원) · 두 칸 타일 · 오른쪽 세로 바입니다. 아래 본문은 Horarium 시절에 쓴 것이라 이름과 화면 설명이 옛것인 곳이 있습니다. 기준은 `DESIGN.md` 입니다.

연구실 PC 에서 **내가 언제 출근해서 무엇을 하며 얼마나 있었는지**를 자동으로 기록하는 개인용 앱입니다.
전경 창(지금 보고 있는 프로그램·창 제목)을 2초마다 확인해 집중 / 실험 / 딴짓 / 자리비움 같은 카테고리로 하루를 색칠한 타임라인을 보여 줍니다.
서버·클라우드·계정 없음. 모든 데이터는 이 PC 안에만 저장됩니다.

## 1. 처음 실행

1. `출근기록_열기.bat` 을 더블클릭합니다.
2. 트래커(기록기)와 로컬 서버가 숨김으로 켜지고, 2초 뒤 Chrome(없으면 Edge) 앱 창으로 화면이 열립니다.
   - 화면은 **앱 전용 브라우저 프로필**(`%LOCALAPPDATA%\MAENG_worklogrowser-profile`)로 열립니다. 평소 쓰는 크롬 프로필 선택창과 무관하게 항상 바로 뜹니다.
   - 처음 한 번은 크롬이 새 프로필을 만드느라 5초 정도 걸릴 수 있습니다.
3. 창을 닫아도 기록은 계속됩니다. 다시 보고 싶으면 `출근기록_열기.bat` 을 또 더블클릭하면 됩니다(중복 실행되지 않음).

> 처음 몇 분은 타임라인이 거의 비어 있는 게 정상입니다. 창을 바꿔 가며 일하다 보면 채워집니다.

3. 다음 부팅부터 로그인하면 트래커와 서버가 자동으로 켜집니다. 화면은 필요할 때 `출근기록_열기.bat` 으로 엽니다.

## 3. 화면 설명

| 위치 | 내용 |
|---|---|
| 상단 | 날짜 이동(`◀ 오늘 ▶`, 날짜 선택), 상태 배너(`● 기록 중` / `⏸ 일시정지` / `● 끊김`) |
| 왼쪽 타임라인 | 세로 막대. 1분 = 1px. 색 = 카테고리. 마우스를 올리면 시간·프로그램·제목이 보이고, **클릭하면 재분류 팝업**이 뜹니다. 오늘이면 남색 선이 현재 시각. |
| 오른쪽 요약 카드 | 출근 → 퇴근, 활동시간, 딴짓(분·비율·진입 횟수), 자리비움/원격, 최장 집중 |
| 일시정지 | `1시간` `오늘 종일` `재개` 버튼 |
| 미분류 Top 5 | 규칙에 안 걸린 프로그램. 클릭해서 카테고리를 정해 주면 다음부턴 자동 분류 |
| 투두 | 오늘 할 일 + 이월된 할 일(`오늘로` 버튼) |
| 메모 | 오늘 메모 / 고정 메모 (입력하면 1초 뒤 자동 저장) |
| 범례 | 카테고리 색 |

카테고리: **집중**(파랑) · **실험**(초록) · **회의**(청록) · **휴식**(주황) · **딴짓**(빨강+사선) · **중립**(연회색) · **미분류**(회색) · **자리비움**(회색 사선) · **원격**(보라) · **일시정지**(점선) · **꺼짐**(빈칸 = 트래커가 안 돌던 시간).

- **활동시간** = 집중~미분류(active) 구간의 합. **출근** = 그날 첫 active 구간 시작, **퇴근** = 마지막 active 구간 끝.
- 하루 경계는 **새벽 4시**입니다. 새벽 2시에 한 일은 전날로 들어갑니다.

## 4. 딴짓 오판 고치기 (재분류)

1. 타임라인에서 잘못 색칠된 **막대를 클릭**합니다.
2. 팝업에서 올바른 **카테고리 버튼**을 누릅니다.
3. 적용 범위를 고릅니다.
   - `이 구간만` → 그 시간대만 정정 (다시 클릭해서 `정정 취소` 가능)
   - `이 프로그램(exe)은 앞으로 항상` → 그 실행파일은 이후 항상 그 카테고리
   - `제목에 "…"가 들어가면 앞으로 항상` → 창 제목 키워드 규칙 (키워드는 수정 가능)
4. 화면이 바로 새로고침됩니다. 규칙은 `rules.json` 에 저장됩니다.

자리비움·일시정지·원격 구간도 클릭해서 `이 구간만` 실험/회의/휴식 등으로 태깅할 수 있습니다(예: 측정 중 자리 비움 → 실험).

## 5. rules.json 손으로 고치기

`C:\Users\PC1\Documents\MAENG_worklog\rules.json` 을 메모장으로 열어 편집해도 됩니다. 저장하면 다음 화면 갱신부터 바로 반영됩니다(재시작 불필요).

```json
{"target": "title", "pattern": "YouTube", "is_regex": false, "category": "distraction",
 "priority": 200, "idle_limit_sec": null, "enabled": true, "note": "설명(선택)"}
```

| 필드 | 뜻 |
|---|---|
| `target` | `"exe"` = 실행파일 이름(`chrome.exe`)에 매칭, `"title"` = 창 제목에 매칭 |
| `pattern` | 찾을 문자열. `is_regex` 가 `true` 면 정규식(대소문자 무시). `"A\|B\|C"` 처럼 `\|` 로 여러 개 |
| `category` | `focus` 집중 / `experiment` 실험 / `meeting` 회의 / `break` 휴식 / `distraction` 딴짓 / `neutral` 중립 / `unknown` 미분류 |
| `priority` | 숫자가 클수록 먼저 검사. 첫 매치가 채택됨. 기본 규칙은 제목 200~300, exe 100. UI 에서 추가한 규칙은 exe 150 / 제목 350(기본 제목 규칙보다 항상 우선) |
| `idle_limit_sec` | 무입력 상태여도 이 초 동안은 카테고리 유지. `null` 이면 카테고리 기본값 사용(§7) |
| `enabled` | `false` 면 규칙을 끈 채로 보관 |

- `rules.default.json` 은 원본 백업입니다. `rules.json` 을 지우면 다음 실행 때 원본이 다시 복사됩니다.
- 파일이 깨지면(JSON 오류) 규칙이 전부 무시되어 모두 **미분류**로 나옵니다. 쉼표·따옴표를 확인하세요.

## 5-1. 이름 표시 (막대·툴팁·미분류에 exe 대신 '무엇을 했는지')

타임라인 막대 라벨, 툴팁 첫 줄, 미분류 Top 5 는 `chrome.exe` 같은 실행파일 이름 대신 **표시 이름**(Claude, ChatGPT, Athenaeum, 네이버, PowerPoint …)을 씁니다. 원문 제목·exe 는 툴팁/팝오버에 그대로 남습니다. 규칙 파일은 `names.json` (원본 백업 `names.default.json`, 지우면 다시 복사됨). 편집 화면은 없고 메모장으로 고치면 다음 화면 갱신부터 반영됩니다. `GET /api/names` 로 현재 내용을 볼 수 있습니다.

```json
{
  "browsers": ["chrome.exe", "msedge.exe"],
  "strip": ["\\s*-\\s*(Google )?Chrome$", "\\s*-\\s*프로필 \\d+\\s*-\\s*Microsoft Edge$", "\\s*외 페이지 \\d+개"],
  "title": [
    {"pattern": "ChatGPT", "name": "ChatGPT"},
    {"pattern": "Athenaeum|Paperdesk|(19|20)[0-9]{2} 읽기", "name": "Athenaeum", "is_regex": true},
    {"pattern": "(^|\\\\)claude(\\.exe)?$", "name": "Claude Code", "is_regex": true, "exe": "WindowsTerminal.exe"}
  ],
  "exe": {"POWERPNT.EXE": "PowerPoint", "KakaoTalk.exe": "카카오톡", "explorer.exe": "탐색기"}
}
```

이름이 정해지는 순서 (첫 번째로 걸리는 것이 채택, 모두 대소문자 무시):

1. `title` 규칙을 위에서부터 창 제목에 대조 (`is_regex` 가 없으면 포함 여부, `true` 면 정규식). `exe` 를 적어 두면 그 실행파일일 때만 적용 — 터미널의 `claude` 탭은 "Claude Code", 데스크톱 앱은 "Claude" 로 나누는 식.
2. 실행파일이 `browsers` 면 제목에서 `strip` 정규식을 차례로 지우고 남은 글자(최대 40자)가 이름. 예: `프로젝트 일람 | meviy(메비) | 한국미스미 - Chrome` → `프로젝트 일람 | meviy(메비) | 한국미스미`, `새 탭 - Chrome` → `새 탭`. 아무것도 안 남으면 `exe` 표의 브라우저 이름(`Edge`, `Chrome`).
3. `exe` 표에 있으면 그 이름.
4. 그 외는 exe 에서 `.exe` 를 뗀 것 (`foo.exe` → `foo`). 창이 없으면 `(창 없음)`.

**이름이 이상할 때** (예: 자주 가는 사이트가 긴 제목 그대로 나올 때): `title` 목록에 한 줄 추가하면 됩니다. 순서가 중요하므로 구체적인 규칙을 위에, 넓은 규칙(`네이버`, `\\.pdf`)을 아래에 두세요. 잘못된 정규식은 무시되고, 파일이 깨지면(JSON 오류) 규칙 전체가 꺼져 exe 이름만 나옵니다. 이 규칙은 **표시 이름만** 바꾸며 분류(집중/딴짓)에는 영향이 없습니다 — 분류는 `rules.json`.

## 5-2. 학교 공지 (대학원 · 기계공학과)

사이드바 **학교 공지** 카드에 홍익대 **대학원**(`notice-grad.do`)과 **기계공학과**(`0701.do`) 게시판의 새 글이 뜹니다. 목적은 **받을 수 있는 장학·포상을 놓치지 않는 것** — 그래서 전부 보여 주지 않고 다음처럼 골라 냅니다.

| 등급 | 뜻 | 예 |
|---|---|---|
| `top` | 카드 위에 바로 표시 | 대학원 장학금 1·2차 신청, 봉사장학생 선발, 학생 포상, 석사우수장학생(이공계), 조교·근로학생·튜터·봉사학생 모집, 차세대공학리더(YEHS) 같은 학술 프로그램 |
| `info` | `… n건 더 보기` 를 눌러야 나옴 | 등록금 분납·학자금 대출, 논문지도교수 신청, 종합·외국어시험, 휴학·수강신청 |
| `hide` | 아예 안 보임 | International Students / 留学生 대상 공지 |
| `other` | 나머지 (기본 숨김) | 학점교류, 연구윤리교육 … |

- 제목에 마감이 적혀 있으면(`~9.20`, `(4.6.(월)~4.10.(금))`, `~9/11(금) 11시까지` 등 **마지막 날짜**) `D-3` 로 표시하고, 3일 이내면 노란색, 지난 것은 회색으로 맨 아래에 둡니다. 연말에 올라온 `~1.15` 는 이듬해로 봅니다.
- 제목을 누르면 원문이 새 탭에서 열리고 그 글은 읽음 처리됩니다. 오른쪽 `×` 는 읽음 처리만 합니다.
- **6시간에 한 번**, 화면을 열 때 백그라운드로 받아 옵니다(화면이 느려지지 않게 응답은 먼저 나갑니다). 지금 바로 받고 싶으면 카드 오른쪽 `새로고침`.
- 게시판당 2페이지(40건)만 받고 요청 사이에 0.3초를 쉽니다. 학교 서버에 부담을 주지 않기 위한 것이니 `pages_per_board` 를 크게 올리지 마세요.
- **인터넷이 안 되면 카드에만 조용히 표시**되고 나머지 기능(타임라인·메모·할 일)은 그대로 돌아갑니다. 연구실 방화벽이나 오프라인에서도 앱은 멀쩡합니다.
- 180일이 지난 공지는 자동으로 지워집니다(`keep_days`).

규칙 파일은 `notices.json` (원본 `notices.default.json`, 지우면 다시 복사됨). 메모장으로 고치면 다음 새로고침부터 반영됩니다.

```json
{ "version": 3,
  "fetch_interval_hours": 6, "pages_per_board": 2, "keep_days": 180, "timeout_sec": 15, "sleep_sec": 0.3,
  "boards": [
    {"id": "grad", "name": "대학원", "list_url": "https://www.hongik.ac.kr/kr/education/notice-grad.do", "enabled": true},
    {"id": "me",   "name": "기계공학과", "list_url": "https://me.hongik.ac.kr/me/0701.do", "enabled": true}
  ],
  "rules": [
    {"tier": "hide", "pattern": "留学生|International Students", "is_regex": true},
    {"tier": "top",  "pattern": "포상|우수장학|연구재단|지원사업|공학한림원|학술대회", "is_regex": true, "tag": "연구·실적"},
    {"tier": "top",  "pattern": "장학", "tag": "장학"},
    {"tier": "top",  "pattern": "조교|근로학생|튜터링|봉사학생", "is_regex": true, "tag": "근로·조교"},
    {"tier": "info", "pattern": "등록금|분납|학자금", "is_regex": true, "tag": "등록"}
  ],
  "category_tier": {"장학": "top"},
  "profile": { "과정": "일반대학원 석사과정 1학기차", "…": "§5-3 참고" } }
```

- 규칙은 **위에서부터 첫 매치**. 그래서 `hide` 를 맨 위에 둡니다(외국인 대상 장학 공지는 숨김이 이김). 어디에도 안 걸리면 `other`.
- 대조 대상은 **대학원 게시판의 카테고리 + 제목**입니다(`留学生` 는 카테고리에만 나오기 때문). `is_regex` 가 없으면 포함 여부.
- `category_tier` 는 규칙보다 **먼저** 적용됩니다 — 대학원 게시판에서 카테고리가 `장학` 이면 제목에 '장학' 이 없어도 위로 올라옵니다.
- `tag` 는 카드에 붙는 배지 글자입니다(`연구·실적`, `장학`, `근로·조교` …).
- 기계공학과 게시판은 카테고리가 없어 대부분 `other` 로 떨어집니다. 놓친 것이 보이면 `rules` 의 알맞은 줄에 키워드를 하나 더하세요(예: 새 재단 이름). 반대로 학부 전용 공지가 위로 올라오면 맨 위에 `hide` 줄을 한 줄 더하면 됩니다.
- 게시판을 잠시 끄려면 `enabled: false`. 다른 학과 게시판을 추가하려면 같은 모양으로 `boards` 에 한 줄 넣으면 됩니다(같은 CMS 면 그대로 파싱됩니다).
- `notices.default.json` 의 `version` 이 올라가면(기본 규칙이 고쳐지면) `notices.json` 을 새로 복사하고 옛 파일을 `notices.json.bak` 으로 남깁니다 — `names.json` 과 같은 방식(§5-1).

## 5-3. 공지 하나를 읽고 "내가 뭘 할 수 있나" 뽑아 주기

공지 제목만 봐서는 **내가 신청할 수 있는 건지** 알 수 없습니다(면학장학금은 복학자만 안 되는지, 이공계우수 받는 중에도 되는지 …). 그래서 각 공지 행 오른쪽에 **`분석`** 버튼이 있습니다.

- 누르면 그 공지의 **본문을 읽어** 신청 대상·금액·기간·제출처·서류를 뽑고, **내 상황에 비춰** 신청 가능 여부까지 판단해 행 아래에 펼쳐 보여 줍니다.
- 판정은 네 가지입니다: **가능**(초록) · **확인필요**(노랑) · **불가** · **해당없음**(둘 다 회색).
- 결과에는 `할 일` 목록이 붙습니다 — "소속 학과 조교에게 학과 자체 마감일을 확인한다", "클래스넷-개인정보에서 계좌정보를 갱신한다" 처럼 지금 당장 할 수 있는 것으로 최대 4개.
- `주의` 줄에는 **중복수혜 제한**이나 필수 이수 교육 같은 함정이 적힙니다. 이미 등록금 전액 면제를 받고 있으면 감면형 장학금은 차액만 나와 실익이 거의 없고, 봉사·강의운영보조 같은 **근로형은 이중수혜가 되는** 경우가 있는데 그 차이를 짚어 줍니다.
- 한 번 분석한 공지는 결과가 저장됩니다. 제목 옆에 작은 점(판정 색)이 생기고, 다시 누르면 **기다림 없이 바로** 펼쳐집니다. 펼침은 한 번에 하나만 열립니다.
- 아래쪽 `첨부 …` 는 그 글에 붙은 파일 이름, `원문 열기` 는 학교 홈페이지 원문입니다.

### 어떻게 판단하나요

- 분석은 이 PC 에 설치된 **`claude` 명령**(논문 앱 Athenaeum 과 같은 것)이 합니다. **구독으로 도는 것이라 API 키를 따로 넣을 필요가 없습니다.**
- `claude` 가 없으면 **분석 기능만 조용히 꺼집니다** — 공지 카드·마감일·새로고침은 그대로 동작합니다.
- 한 건에 **20~40초**쯤 걸립니다. 누른 글만 분석하고(자동 분석 없음), 같은 글의 본문은 학교 서버에서 한 번만 받아 재사용합니다. 동시에는 두 건까지 돌립니다.
- **본문에 없는 내용은 지어내지 않도록** 시켜 두었습니다. 근거가 모자라면 `가능`/`불가` 대신 **`확인필요`** 가 나오고, 무엇을 어디에 확인해야 하는지 알려 줍니다. 그래도 **최종 확인은 원문과 학과 조교**에게 하세요.

### 내 상황 고치기 (`notices.json` 의 `profile`)

판단의 기준이 되는 내 정보입니다. 학기가 바뀌거나 장학 상황이 달라지면 메모장으로 고치면 됩니다 — 다음 분석부터 반영됩니다.

```json
"profile": {
  "과정": "일반대학원 석사과정 1학기차",
  "학과": "기계·시스템디자인공학과(기계공학)",
  "현재 장학": "이공계우수장학금 수혜 중 — 1년간 등록금 전액 면제, 2년차 반액",
  "상태": "재학생(휴학·복학·수료 아님), 내국인, 남성, 군필 아님/해당없음",
  "관심": "연구·논문 실적으로 받는 추가 장학·포상, 이중수혜 가능한 근로·조교 장학"
}
```

- 항목 이름은 자유입니다. `"연구실"`, `"지도교수"`, `"자격증"` 처럼 필요한 줄을 더해도 됩니다(최대 20줄, 한 줄 400자).
- **여기에 적은 내용이 판단에 그대로 쓰입니다.** 예를 들어 `"상태"` 에서 `복학` 을 빼 두면 '복학자 불가' 조건에 걸리지 않는다고 봅니다. 사실과 다르게 적으면 엉뚱한 답이 나옵니다.
- 이미 분석해 둔 결과는 프로필을 고쳐도 **자동으로 다시 계산되지 않습니다**. 새 프로필로 다시 판단시키려면 그 공지를 펼치고 아래쪽 **`다시 분석`** 을 누르세요(옛 결과는 덮어써집니다).

## 7-1. 원격 접속 감지

- 집 등에서 이 PC 에 원격으로 붙어 일한 시간은 **원격**(보라)으로 표시하고 출근·활동시간에서 뺍니다.
- 자동으로 잡는 것: **Windows 원격 데스크톱(RDP)** 과 **Jump Desktop**(Jump Desktop Connect 가 Windows 이벤트 로그에 남기는 연결/종료 기록을 5초마다 읽음).
- Jump 는 연결 종료 기록이 빠질 때가 있어(PC 재부팅 등) 종료 없이 **3시간**이 지나면 끝난 것으로 봅니다(`config.json` → `remote_detect.max_session_hours`). 종료 기록이 그 뒤에 오면 그 시각으로 고쳐 줍니다. 재부팅 전에 열린 연결은 부팅 시각에 끝난 것으로 봅니다. 일시정지·절전 중에 생긴 연결/종료 기록도 놓치지 않습니다.
- 수집기가 켜질 때 최근 **7일**치 Jump 기록을 되짚어 빠진 원격 구간을 채웁니다(백필, 이미 있는 구간은 건드리지 않음). 손으로 하려면 `python tracker.py --backfill-only`.
- AnyDesk·TeamViewer 등 다른 도구는 자동으로 못 잡습니다 → 그 구간을 클릭해 `원격`으로 태깅하세요.
- 수집기는 `tracker.py` / `common.py` / `remote_jump.py` 가 바뀌면 30초 안에 스스로 재시작하고, 화면 서버가 30초 이상 죽어 있으면 다시 띄웁니다(아이콘을 다시 누를 필요 없음).
